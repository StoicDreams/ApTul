Simple, privacy-focused web tools built to solve real-world development problems

Image Tools

  • Image Converter & Resizer: Resize images and convert between WebP, PNG, JPG, ICO, and BMP, with photo metadata removed.
  • SVG Path Rotator: Rotate SVG path data by any angle and copy the updated path.
  • PNG to WebP Converter: Convert PNG images to smaller WebP files for the web, keeping transparency.
  • JPG to WebP Converter: Convert JPG photos to WebP for faster loading pages, at the quality you choose.
  • WebP to PNG Converter: Convert WebP images to PNG to open and edit them in any app.
  • WebP to JPG Converter: Convert WebP images to JPG for apps and sites that do not accept WebP.
  • PNG to JPG Converter: Convert PNG photos and screenshots to much smaller JPG files.
  • JPG to PNG Converter: Convert JPG photos to PNG to edit them without further quality loss.
  • Favicon Generator: Make a favicon.ico for your website from a PNG, JPG, or WebP image.
  • Image Resizer: Resize images to an exact width or height, keeping their proportions and format.
  • EXIF Remover: Remove GPS location, camera details, and other hidden data from photos before sharing.
  • Image to Base64: Turn an image into a Base64 data URL, with ready-to-paste HTML and CSS.

PDF Tools

  • Merge PDF: Join PDF files into one, in the order you choose, without uploading them.
  • Split PDF: Take pages out of a PDF, or split it into several files, without uploading it.
  • Image to PDF: Turn JPG, PNG, and WebP images into a PDF, one image per page, on A4, Letter, or image-sized pages.

Developer Tools

  • JWT Decoder: Decode JSON Web Tokens to read the header, payload, and expiry, without sending them anywhere.
  • OpenAPI Viewer: View OpenAPI and Swagger docs in JSON or YAML from a link, pasted text, or a file, with schemas, examples, and Try it.
  • JSON Formatter & Validator: Format, validate, and minify JSON, with the line and column of any error.
  • Base64 Encoder & Decoder: Encode text or files to Base64 and decode it back, with UTF-8 and URL-safe support.
  • URL Encoder & Decoder: Percent-encode text for URLs and query strings, or decode it back to readable text.
  • Hash Generator: Get MD5, SHA-1, SHA-256, SHA-384, and SHA-512 hashes of text or files, and check a file against its hash.
  • Unix Timestamp Converter: Convert Unix timestamps to readable dates in UTC and your time zone, and dates back to timestamps.
  • Markdown to HTML Converter: Convert Markdown to clean HTML, with GitHub tables, task lists, and a live preview.
  • Regex Tester: Test JavaScript regular expressions, with highlighted matches, groups, and find and replace.

Color & Design Tools

  • Color Converter: Convert colors between HEX, RGB, HSL, and CMYK, with a color picker and preview.
  • Color Contrast Checker: Check text and background colors against the WCAG AA and AAA contrast levels.

Text Tools

  • Word Counter: Count words, characters, sentences, and paragraphs, with reading and speaking time.
  • Case Converter: Convert text to upper, lower, title, or sentence case, or to camelCase, snake_case, and other code cases.
  • Diff Checker: Compare two texts line by line and see what was added, removed, or changed.

Generators

  • UUID Generator: Generate random version 4 or time-ordered version 7 UUIDs, up to 1,000 at once.
  • Password Generator: Generate strong random passwords with your choice of letters, numbers, and symbols.
  • QR Code Generator: Make QR codes for links, text, Wi-Fi, email, and phone numbers, and download them as PNG or SVG.
  • Lorem Ipsum Generator: Generate placeholder text as paragraphs, sentences, words, or list items, in plain text or HTML.

Introduction

Welcome to Ap Tul, a growing collection of online utilities designed to streamline the day-to-day tasks of software development.

This site is built on a simple philosophy: Necessity breeds creation.

As a software developer, I often encounter niche tasks - like specific file conversions or data formatting - that require simple, immediate solutions. Instead of scouring the web for ad-heavy third-party tools, I build the solutions I need myself and add them here. The result is a library of lightweight, purpose-built tools that prioritize function, speed, and privacy.

Why Use Ap Tul?

  • Built for Real Workflows: Every tool on this site exists because it was needed for a real project.
  • Privacy First: Many online tools require uploading files to a server. My tools, like the Image Converter, utilize technologies like Rust and WebAssembly to process data directly in your browser.
  • No Clutter: No paywalls, no aggressive ads, just the utility you need.

Tool Spotlight: Image Converter & Resizer

I recently needed a fast way to batch-convert PNGs to WebP and resize them for a web project. The result is the Ap Tul Image Converter.

  • Features: Resize images with preserved aspect ratios, convert formats (PNG, WebP, JPG, ICO), and automatically strip sensitive metadata (GPS, EXIF) for enhanced privacy.
  • Tech: Powered by Rust and WebAssembly for native-level performance within the browser.
